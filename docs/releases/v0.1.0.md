# mojo-gguf-core v0.1.0

**Released:** 2026-10-21 · **Commit:** the one tagged v0.1.0 · **Previous:** first release

## What it does

Read and write GGUF model files from Mojo: an mmapped zero-copy reader and a writer with gguf-py's bytes.

## Highlights

- Opens a 20.9 GB model and reads its 248k-token vocabulary in 36 ms at 29 MB (gguf-py: 5,535 ms, 863 MB; `scripts/bench.sh`).
- Accepts and rejects what gguf-py's GGUFReader does on 20 test files.
- Writes byte-identical GGUFWriter output, 34 ggml types.

## Changes

First public release, no earlier version.

## Known limits

- Little-endian files only.
- `Writer` keeps tensor data in memory until `save`.
- Nested arrays are read and copied (`add_raw`) but have no typed writer call.
